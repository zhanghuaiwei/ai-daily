# 用 Claude Code 写代码总忍不住切屏？试试把状态接到智能灯上

> **导读**｜开源项目 AC Bridge 能把 Claude Code 或 Codex 的运行状态同步到智能灯泡。本文基于公开信息介绍该工具的核心思路与前置条件，由于官方文档细节尚未完全披露，部分配置环节需自行尝试。

---

用 AI 辅助写代码时，最打断思路的动作不是改 Bug，而是反复切回终端看它跑到哪了。一个名叫 AC Bridge 的开源项目试图解决这个问题：把 Claude Code 或 Codex 的运行状态（比如正在等待你确认、或者任务已经完成）直接映射到家中的智能灯泡上。你在 Product Hunt 上能看到它的发布页面，核心卖点只有一句——“你的智能灯会告诉你 AI 什么时候需要你”。

## 开始之前需要准备什么

根据目前公开的信息，要跑通这套流程，你需要同时具备软件和硬件条件。软件端是正在使用 Claude Code 或 Codex 进行编程；硬件端是家里有一盏支持 API 控制的智能灯泡。AC Bridge 本身作为开源桥接工具负责在两者之间传递信号。

关于具体的账号要求、设备型号兼容性以及是否需要额外付费，Product Hunt 页面上仅展示了概念描述，公开信息没有提到更详细的依赖清单。这意味着在动手前，你需要确认自己的智能灯品牌是否开放了控制接口。

## 核心概念：什么是“状态桥接”

理解这个项目只需要弄懂一件事：状态桥接。你可以把它想象成餐厅里的呼叫铃。厨师（AI 编程工具）在后厨做菜时，你不需要一直站在窗口盯着；等菜做好了或者缺食材了，厨师按一下铃，大厅的指示灯就会亮起。

AC Bridge 扮演的就是这个传话人。它监听 AI 编程工具发出的状态变化，然后把这些数字信号翻译成智能灯能听懂的指令，比如变色或闪烁。这样你的注意力就可以留在手头的工作上，而不是屏幕上的终端窗口。

## 如何配置与验证

项目的入口位于 Product Hunt 页面提供的链接中。但必须说明的是，除了产品定位和一句话简介外，官方文档未给出具体的安装命令、菜单路径或提示词模板。因此，从下载源码到让灯泡真正亮起来的具体每一步操作，需要自行尝试。

一个合理的验证标准是明确的：当你故意在 AI 编程工具中触发一个需要人工干预的操作时，观察智能灯是否在几秒内发生了颜色或状态的改变。如果灯随状态同步变化，说明桥接成功；如果没有反应，则说明信号传递链路在某一步断开了。

## 这个做法适合谁

如果你每天花大量时间在终端里和 AI 结对编程，且工位附近刚好有可控的智能灯，这种物理提醒方式能减少无意义的切屏次数。它本质上是用环境光替代视觉焦点转移。

但如果你的智能灯不支持外部接口调用，或者你习惯多屏办公随时能看到终端输出，专门去折腾一套灯光提醒系统就不太值得。对于这类用户，直接在屏幕上挂一个状态小组件可能是更低成本的选择。

AC Bridge 提供了一个将数字状态拉回物理世界的思路。目前它在 Product Hunt 上刚刚露面，具体的配置细节和兼容列表还有待社区进一步补充。如果你手边正好有一套智能家居设备和一个跑得正欢的 AI 编程助手，顺着它给出的方向摸索一下，或许真能让桌上的那盏灯变成你最安静的监工。
