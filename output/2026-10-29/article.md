# 有人把一颗CPU塞进了大模型权重里，还能跑代码：没那么简单

> **导读**｜开发者Divyansh Agrawal将一颗32位RISC\-V CPU直接编码进Qwen3\.5\-4B的模型权重中。这颗虚拟处理器利用模型自身的注意力层作为内存，无需任何外部工具即可在推理时执行算术、C语言和MicroPython代码。

---

如果你让大模型算一道复杂的乘法题，它大概率会靠“猜”给出一个看起来合理的答案。但最近，一位名叫 Divyansh Agrawal 的开发者做了一件极其硬核的事：他把一颗真正的计算机处理器（CPU）直接塞进了 Qwen3\.5\-4B 大模型的权重文件里。这意味着，当你向这个改造后的模型提问时，它不再单纯依靠概率预测下一个字，而是可以在内部启动一颗真实的芯片去精确计算，然后把结果告诉你。

## 不用硅片，用神经网络造一台电脑

这个名为 Qwenputer 的实验项目，本质上是一颗 32 位的 RISC\-V 处理器。RISC\-V 是一种开源的芯片指令集架构，你可以把它理解为电脑能听懂的最底层的语言。通常，这种处理器需要刻在物理硅片上才能工作。但在 Qwenputer 中，这颗 CPU 完全由数学公式构成，被直接“编译”成了神经网络的参数。

这里的核心难点在于内存。真实的 CPU 需要随机存取存储器（RAM）来暂存数据。Qwen3\.5 模型内部使用了一种叫 Gated DeltaNet 的线性循环神经网络机制来处理上下文。Divyansh 发现，只要把这个机制里的几个关键参数固定——比如让控制遗忘的“门”永远保持为 1，让写入强度达到最大——这块原本用来记忆上下文的网络区域，就会变成一块绝对精确的内存。写入一个值，它就原封不动地待在那里；查询一个地址，它就能准确返回对应的数据。

有了精确的内存，剩下的就是逻辑电路。整个过程不需要对大模型进行任何重新训练。开发者写了一个编译器，把 CPU 的每一个动作（比如读取寄存器、两数相加、条件跳转）翻译成神经网络层中的特定结构。最终，这颗虚拟 CPU 占据了模型最前面的 11 层，而后面依然保留着 Qwen 原本的 32 层用于理解自然语言。

## 它能干什么？

目前公开的信息显示，Qwenputer 已经通过了官方的 riscv\-tests 测试集，其运行结果与标准的 QEMU 模拟器完全一致。更夸张的是，它在没有任何外部参考机器纠正的情况下，连续自主运行了 1800 万条指令，没有出过一次错。

在实际使用中，模型能够利用这颗内置的 CPU 执行算术运算，甚至运行 C 语言和 MicroPython 代码。为了让大模型知道什么时候该调用这颗 CPU，开发者采用了一个取巧的办法：借用大模型本身就很熟悉的“工具调用”格式。当模型判断需要计算时，它会生成特定的指令令牌（Token），这些令牌实际上就是 CPU 的执行轨迹。CPU 在模型内部跑完程序后，再把结果作为“工具响应”写回给模型，模型接着用人类的语言把答案输出给你。

不过，这毕竟是一个实验性质的项目。它的运行速度相对较慢，而且目前实现的只是一颗基础的 32 位核心，还远远达不到运行 Linux 操作系统的级别。

## 为什么这件事值得关注？

长期以来，大模型最大的短板之一就是精确计算和逻辑执行能力。目前的常规做法是让大模型通过 API 去调用外部的计算器或代码解释器。但这不仅增加了延迟，还引入了外部依赖和安全风险。

Qwenputer 提供了一种完全不同的思路：把确定性的硬件逻辑，直接融合进概率性的神经网络中。Reddit 社区 r/LocalLLaMA 的讨论指出，这种“模型即硬件”的架构，可能对未来的 AI 工具调用和计算机操控产生深远影响。如果大模型内部自带一个无法被篡改的微型计算机，那么它在执行复杂任务时的可靠性将大幅提升。

开发者还在博客中提到了两个基于此的后续实验方向：一是研究混合模型如何利用这种内部状态隐藏推理过程以逃避监控；二是探讨这种编译进权重的组件能否作为模型自身无法破坏的内置安全监控工具。虽然这些只是初步设想，但它证明了在模型权重层面进行底层架构改造的巨大潜力。

## 普通人能玩到吗？

如果你对底层技术感兴趣，Qwenputer 的代码和模型权重已经在 GitHub、Hugging Face 和 ModelScope 上开源。开发者也提供了一个在线的 Live Demo 供人体验。

对于普通读者来说，你不需要去下载几十 GB 的模型文件。但这个实验传递了一个清晰的信号：大模型的边界正在被重新定义。它不再只是一个只会接话的文字游戏机，研究人员正在尝试让它长出真正的“骨骼”和“内脏”。当语言模型开始在体内像真实芯片一样逐条执行机器指令时，AI 辅助编程和自动化操作的底层逻辑，或许正在发生某种不易察觉的改变。

---

目前，Qwenputer 依然是一个极具想象力的极客实验，距离进入日常应用还有很长的路要走。但它用一种近乎暴力的优雅方式证明了一件事：在神经网络的数学空间里，真的可以藏下一台完整的计算机。
